👁️ Amati: garis keputusan + lampu output

💡 MATI

Titik hijau = input kamu. Latar biru/kuning = daerah keputusan neuron. Geser w₁/w₂ → garis berputar. Geser b → garis bergeser.

📐 Intuisi rumus: z = w₁·x₁ + w₂·x₂ + b → jumlahkan semua (bobot × input) lalu tambah bias. y = 1 jika z > 0 → lampu menyala kalau totalnya positif. Bobot = pentingnya input. Bias = standar kelulusan.
Lanjut: Aktivasi →
💡 Analogi: Fungsi aktivasi = aturan “kapan lampu menyala”. Step = saklar tegas. Sigmoid = dimmer lembut. ReLU = “negatif cuekin, positif terusin”.

🎛️ Coba ubah

Tanpa aktivasi non-linear, 100 layer pun cuma bisa bikin garis lurus! Makanya ReLU/sigmoid wajib ada.

👁️ Grafik + kemiringan (gradien)

📐 Intuisi: Sigmoid 1/(1+e⁻ˣ) = peluang. Tanh = versi −1..1. ReLU max(0,x) = buang negatif. Kemiringan grafik = seberapa cepat neuron belajar (gradien).
Lanjut: Jaringan →
🏃 Analogi: MLP = estafet. Lapisan 1 meringkas “ada garis?”, lapisan 2 meringkas “ada bentuk?”, lapisan akhir memutuskan “ini kucing!”.

👁️ Aliran forward pass (2 → 3 → 2 → 1)

Angka mengalir kiri → kanan. Ketebalan garis = besar bobot (biru positif, merah negatif).

📐 Intuisi: Tiap panah = kali + jumlah + aktivasi. Jaringan dalam = menumpuk banyak neuron sederhana hingga bisa mengenali pola rumit.
Lanjut: Loss →
🎯 Analogi: Loss = jarak lemparan dart dari bullseye. Makin jauh meleset, makin besar loss. Tugas model = memperkecil jarak ini.

🎛️ Coba ubah

👁️ Kurva loss

Geser tebakan ke arah target → loss turun ke lembah. Cross-entropy menghukum “salah tapi pede” jauh lebih keras!

📐 Intuisi: MSE (y−ŷ)² = kuadrat selisih. Cross-Entropy −[y·log ŷ + (1−y)·log(1−ŷ)] = “kaget”-nya model saat salah.
Lanjut: Gradient →
⛷️ Analogi: Gradient descent = bola ski dalam kabut. Tidak lihat lembah, hanya rasakan “miring ke mana kaki saya?” lalu melangkah ke bawah.

🎛️ Coba ubah

Coba lr=0.02 (pelan tapi pasti), lr=0.2 (pas), lr=0.95 (mental-mental/divergen!).

👁️ Lembah loss (fungsi x² + sedikit gelombang)

📐 Intuisi: w_baru = w_lama − lr × kemiringan. lr = panjang langkah. Kemiringan + → melangkah kiri, kemiringan − → melangkah kanan.
Lanjut: Backprop →
⚽ Analogi: Backprop = evaluasi tim kalah. Bukan cuma kiper yang salah — kesalahan dibagi ke belakang: siapa passing buruk? Siapa salah posisi?

🎛️ Langkah demi langkah

Jaringan mini: 2 input → 1 neuron → output. Target = 1.

👁️ Alur mundur (4 langkah)

  1. 1. Forward: hitung tebakan ŷ dari input & bobot.
  2. 2. Loss: hitung error = ŷ − target.
  3. 3. Backward: bagi error ke tiap bobot (gradien = error × input).
  4. 4. Update: koreksi bobot: w −= lr × gradien.
📐 Intuisi chain rule: “Seberapa salah output jika bobot digeser dikit?” = (salahnya output) × (pengaruh bobot ke output). Bobot dengan input besar → tanggung jawab besar.
Lanjut: Overfitting →
📚 Analogi: Overfitting = siswa menghafal kunci jawaban. Nilai latihan 100, tapi ujian (soal baru) anjlok. Model terlalu “pintar menghafal noise”.

👁️ Kurva fit vs data (titik = data, garis = model)

Derajat 1 = underfit (terlalu lurus). 3–4 = pas. 9 = overfit (meliuk menghafal noise, error uji meledak).

📐 Intuisi: Model sederhana = penggaris. Model kompleks = tali lentur. Tali bisa menempel ke semua titik (termasuk salah) tapi jelek untuk titik baru. Obat: data lebih banyak, model lebih sederhana, early stopping.
Lanjut: CNN →
🔦 Analogi: Konvolusi = menggeser stensil di atas gambar dan bertanya tiap posisi: “ada garis vertikal di sini? ada tepi?”. Pooling = meremas gambar agar lebih kecil tapi intinya tetap.
