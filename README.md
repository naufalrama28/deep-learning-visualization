# Deep Learning Visualization — Belajar Deep Learning Sambil Mengutak-atik 🧠

Website interaktif **Bahasa Indonesia** untuk pemula/awam: setiap konsep deep learning bisa **dilihat, digeser, diubah, dan dicoba langsung** — tanpa install, tanpa coding dulu.

![Tanpa dependensi](https://img.shields.io/badge/dependensi-nol-brightgreen) ![Bahasa](https://img.shields.io/badge/bahasa-Indonesia-blue) ![Offline](https://img.shields.io/badge/offline-bisa-orange)

## ✨ Fitur
- **11 modul visual**: Neuron, Aktivasi, MLP, Loss, Gradient Descent, Backprop, Overfitting, CNN, RNN, Attention, + **Playground klasifikasi 2D**
- **Semua bisa diatur**: 60+ slider/tombol — bobot, bias, learning rate, filter, dataset, arsitektur
- **Contoh 1-klik**: preset AND/OR, filter tepi/blur, kalimat attention, dataset spiral/XOR
- **Kuis cek-paham** tiap modul + progress tersimpan otomatis
- **Dark/Light mode**, responsif HP & laptop, 100% offline

## 🚀 Cara Membuka (pilih 1)

**1. Klik 2x (paling mudah):**
Buka folder ini → klik 2x `index.html`.

**2. Pakai Python (disarankan):**
```powershell
cd D:\Coding\deep-learning-visualization
python -m http.server 8000
# buka http://localhost:8000 di Chrome/Edge
```

**3. Pakai Node:**
```powershell
npx serve .
```

## 🗺️ Mulai Belajar
1. Buka **Modul 2 (Neuron)** jika benar-benar dari nol.
2. Ikuti urutan di `LEARNING_PATH.md` (10–15 mnt/modul).
3. Tiap modul: baca analogi → geser slider → klik preset contoh → jawab kuis → centang selesai.
